# Подробная инструкция по установке CAMAI бдительность (CAMAI vigilance)

Инструкция рассчитана на **Radxa ROCK 5T** с **Radxa OS** (Debian 12 «bookworm» с рабочим столом).
Те же шаги подходят для Ubuntu 22.04/24.04 на RK3588 и для обычного ПК с Debian/Ubuntu.

## 1. Что понадобится

| Что | Требование |
|-----|-----------|
| Плата | Radxa ROCK 5T (RK3588) или любой ПК с Linux (aarch64 / x86_64) |
| ОС | Radxa OS (Debian 12) с графическим рабочим столом; Ubuntu 22.04/24.04 тоже подходит |
| Python | 3.9 или новее (в Debian 12 — 3.11, ставится вместе с ОС) |
| Камера | **USB-веб-камера (UVC) — рекомендуется**. MIPI-камера — см. [раздел 10](#mipi-камера) |
| Сеть | Интернет на время установки: пакеты apt, ~200 МБ пакетов Python, ~41 МБ моделей |
| Диск | ≥ 1 ГБ свободного места |
| Звук | HDMI-звук монитора, колонки или наушники (для сигнала по п.6) |
| Права | Обычный пользователь рабочего стола с правом `sudo` (нужен только во время установки) |
| Время | 15–30 минут |

Программа устанавливается **для одного пользователя** — того, под которым работают за этим экраном.
Устанавливайте и запускайте её от имени этого пользователя, **не от root**.

## 2. Подготовка системы

Откройте терминал (в KDE: меню → «Система» → Konsole).

**2.1. Обновите систему** и перезагрузитесь:

```bash
sudo apt update && sudo apt full-upgrade -y
```

```bash
sudo reboot
```

**2.2. Проверьте архитектуру, версию ОС и Python:**

```bash
uname -m; grep PRETTY_NAME /etc/os-release; python3 --version
```

Ожидается: `aarch64`, `Debian GNU/Linux 12 (bookworm)` (или Ubuntu), `Python 3.9` или новее.

**2.3. Проверьте тип графического сеанса:**

```bash
echo $XDG_SESSION_TYPE
```

* `x11` — оптимально.
* `wayland` — программа работает (запускается через XWayland), но красная рамка может не
  отображаться поверх полноэкранных окон. Рекомендуется перейти на X11: выйдите из системы и на
  экране входа выберите сеанс **«Plasma (X11)»** (KDE) или **«Ubuntu on Xorg»** (GNOME) —
  обычно это меню в углу экрана входа.

**2.4. Установите git** (если будете получать программу через git):

```bash
sudo apt install -y git
```

## 3. Подключение и проверка камеры

1. Закрепите камеру **по центру верхней кромки монитора**, объективом на пользователя.
   Рабочее расстояние до лица — 40–100 см. Избегайте яркого окна за спиной пользователя.
2. Подключите камеру к USB-порту платы.
3. Найдите устройство камеры:

```bash
sudo apt install -y v4l-utils
```

```bash
v4l2-ctl --list-devices
```

На RK3588 в списке много аппаратных устройств (`rkisp`, `rkcif`, `hdmirx`, `rga`, `mpp` …) —
их пропускайте. USB-камера видна по названию модели, например:

```
HD Pro Webcam C920 (usb-xhci-hcd.1.auto-1):
        /dev/video20
        /dev/video21
```

Запомните **первое** устройство в её блоке (здесь `/dev/video20`) — оно понадобится в
настройках. Второе устройство обычно служебное (метаданные).

4. Проверьте, что камера отдаёт изображение:

```bash
v4l2-ctl -d /dev/video20 --list-formats-ext | head -20
```

Должны быть перечислены форматы (`YUYV`, `MJPG`) и разрешения, среди них 640×480.

## 4. Получение программы

**Вариант А — через git** (на самой плате):

```bash
cd ~ && git clone -b claude/confident-lamport-ak9j6q https://github.com/liharev/eyetracker.git
```

Если репозиторий приватный, git запросит логин GitHub и **токен доступа** вместо пароля
(GitHub → Settings → Developer settings → Personal access tokens). После слияния ветки в
основную параметр `-b claude/confident-lamport-ak9j6q` можно не указывать.

**Вариант Б — архивом** (если на плате нет доступа к GitHub):

1. На другом компьютере откройте репозиторий на GitHub, выберите нужную ветку,
   нажмите **Code → Download ZIP**.
2. Перенесите архив на плату (флешка или `scp eyetracker.zip radxa@<IP-платы>:~`).
3. Распакуйте:

```bash
sudo apt install -y unzip
```

```bash
cd ~ && unzip eyetracker-*.zip && mv eyetracker-*/ eyetracker
```

## 5. Запуск установщика

```bash
cd ~/eyetracker && ./install.sh
```

Скрипт один раз спросит пароль `sudo` и выполнит:

| Шаг | Что происходит |
|-----|----------------|
| Системные пакеты | `python3-venv`, `python3-pyqt5` (интерфейс), `pulseaudio-utils`/`alsa-utils` (звук), `v4l-utils`, `libxcb-cursor0` |
| Виртуальное окружение | `~/.local/share/eyetracker/venv` — изолированное, системный Python не затрагивается |
| OpenCV | `opencv-python-headless` (детекция и распознавание лиц) |
| NPU RK3588 | только на aarch64: библиотека `librknnrt.so` 2.5.0 (с проверкой SHA-256) в `~/.local/share/eyetracker/lib` и модели `.rknn` в `~/.local/share/eyetracker/models/rknn`; пользователь добавляется в группу `render` (доступ к NPU) |
| LiteRT | быстрое выполнение модели точек лица (оценка взгляда по радужке), ~9 МБ. Если для платформы нет сборки — установка продолжится, модель будет выполняться через OpenCV (немного больше нагрузка). Оставшийся от версии 1.0 MediaPipe удаляется |
| Программа | установка CAMAI бдительность в окружение |
| Модели | YuNet, SFace, FaceLandmarker (~41 МБ) в `~/.local/share/eyetracker/models`, с проверкой SHA-256 |
| Ярлыки | команда `~/.local/bin/eyetracker`, пункт меню «CAMAI бдительность — настройки» и значки программы |
| Доступ к камере | добавление пользователя в группу `video` |
| Проверка | вывод `eyetracker --check` |

Параметры установщика (задаются перед командой):

| Параметр | Назначение |
|----------|-----------|
| `WITH_LITERT=0 ./install.sh` | без LiteRT: модель точек лица выполняется через OpenCV DNN |
| `WITH_NPU=0 ./install.sh` | без поддержки NPU — всё на CPU |
| `APP_HOME=/путь ./install.sh` | другой каталог установки (по умолчанию `~/.local/share/eyetracker`) |

**Проверьте итоговый вывод** (`--check`). Пример для правильно настроенной платы:

```
OpenCV 4.x/5.x: YuNet=да
LiteRT 1.x: модель точек лица выполняется через LiteRT   ← или «нет» — тогда через OpenCV
NPU RK3588: готов; модели .rknn: 4 из 4 — нейросети будут выполняться на NPU
Qt: pyqt5
Модель yunet: /home/radxa/.local/share/eyetracker/models/...
Модель sface: ...
Модель face_landmarker: ...
Камеры: /dev/video0, ..., /dev/video20, /dev/video21
Команды блокировки: loginctl lock-session; gdbus call ...   ← должна быть хотя бы одна
Состояние блокировки определяется: да                       ← «нет» допустимо
Проигрыватели звука: paplay, aplay
Энергоэффективные ядра: [0, 1, 2, 3]                        ← ядра A55 на RK3588
Сеанс: x11 KDE
```

Если установщик сообщил «Пользователь добавлен в группу video», **выйдите из системы и войдите
снова** (или перезагрузитесь) — иначе камера будет недоступна.

## 6. Первый запуск

Запустите программу одним из способов:

* меню приложений → **«CAMAI бдительность — настройки»**;
* в терминале: `~/.local/bin/eyetracker`.

При первом запуске:

1. Появится окно **«Учётная запись администратора»** — задайте логин и пароль (не короче
   4 символов). **Запомните их**: без них нельзя открыть настройки, приостановить контроль или
   закрыть программу.
2. В системном трее (обычно правый нижний угол) появится значок-глаз, откроются настройки.

Если значка нет:

* **KDE**: щёлкните стрелку «Показать скрытые значки» в трее; там же можно закрепить значок.
* **GNOME**: нужно расширение «AppIndicator and KStatusNotifierItem Support»
  (`sudo apt install gnome-shell-extension-appindicator`, затем выйти и войти).
* В любом случае настройки открываются командой `~/.local/bin/eyetracker --settings`
  (программа запускается в одном экземпляре — команда откроет настройки уже работающей копии).

## 7. Настройка по шагам

Изменения вступают в силу по кнопке **«Применить»** или **«OK»**.

### 7.1. Камера

1. Вкладка **«Камера»** → поле **«Источник»**: выберите устройство из [раздела 3](#3-подключение-и-проверка-камеры)
   (например `/dev/video20`) или впишите номер (`0`).
2. Нажмите **«Применить»** — справа должно появиться изображение с рамками вокруг лиц.
3. Если изображение перевёрнуто — **«Поворот»**; если зеркальное — **«Зеркально»**.
4. Разрешение 640×480 и частоту 15 кадр/с менять не нужно — это оптимум по нагрузке.

### 7.2. База авторизованных лиц

1. Вкладка **«База лиц»** → **«Добавить лицо…»**.
2. Введите имя, сядьте как обычно за экран (в кадре — только один человек).
3. Нажмите **«Снять с камеры (10 образцов)»** и в течение ~5 секунд **медленно поворачивайте
   голову** немного влево-вправо и вверх-вниз. Можно также **«Загрузить фото…»** (несколько
   снимков лица анфас).
4. **«Сохранить»**. Повторите для каждого авторизованного пользователя.
5. При необходимости позже: **«Добавить образцы…»** (например, в очках или при другом освещении).

> Пока база пуста, пункты 4, 5 и 6 **не работают** — это защита от блокировки самого себя.

Параметр **«Порог сходства»** (по умолчанию 0.40): если вас иногда принимают за постороннего —
уменьшите до 0.36–0.38; если посторонних принимают за вас — увеличьте до 0.45.

### 7.3. Блокировка (пункты 3–5)

1. Вкладка **«Блокировка»** → нажмите **«Проверить блокировку сейчас»**. Экран должен
   заблокироваться; разблокируйте его своим паролем.
   Если не сработало — выберите **«Своя команда»** и укажите команду для вашего рабочего стола:

   | Рабочий стол | Команда |
   |--------------|---------|
   | KDE Plasma (Radxa OS) | `loginctl lock-session` |
   | Xfce | `xflock4` |
   | GNOME | `gdbus call --session --dest org.gnome.ScreenSaver --object-path /org/gnome/ScreenSaver --method org.gnome.ScreenSaver.Lock` |
   | LightDM (любой) | `dm-tool lock` |

2. Включите нужные пункты и задайте время:
   * **п.3 «никого нет»** — например, таймаут 60 с;
   * **п.4 «нет авторизованного лица»** — например, 10 с;
   * **п.5 «постороннее лицо»** — время подтверждения 2 с.

### 7.4. Контроль взгляда (пункт 6)

1. Вкладка **«Взгляд»** → включите **«Включено»**, задайте **«Красная рамка через»**, **«Мигающая рамка
   через»**, **«Звуковой сигнал через»** (например 5 / 10 / 15 с; каждое следующее — не раньше
   предыдущего). Время отсчитывается с момента, когда взгляд ушёл с экрана.
   **«Уведомление на e-mail через»** (например 60 с) доступно, если на вкладке «Уведомления» для
   события «6. Контроль взгляда» отмечено «E-mail сразу»; письмо отправляется один раз за эпизод.
2. Нажмите **«Применить»**, затем **«Калибровать…»**: сядьте в обычное рабочее положение и по очереди
   смотрите на 5 точек (центр и углы экрана). После калибровки нажмите **«Применить»**.
3. Проверьте строку **«Сейчас»**: при взгляде на экран — «на экране», при взгляде в сторону — «мимо экрана».
4. **Рамка**: толщина, цвет, период мигания; кнопки «Показать рамку» / «Мигающая» / «Скрыть» для проверки.
5. **Звуковой сигнал**: выберите один из трёх встроенных (кнопка ▶ — прослушать) или **«Загрузить…»**
   свой файл (WAV, OGG, FLAC; MP3 — если установлен `ffplay` или `mpv`). Задайте громкость.

### 7.5. Уведомления и журнал

1. Вкладка **«Уведомления»** → таблица **«Куда направлять события»**: для каждого пункта 1–6 и
   служебных событий отметьте **«E-mail сразу»**, **«В журнал»** и/или
   **«Журнал + e-mail по расписанию»**.
2. **Почтовый сервер (SMTP).** Для популярных почтовых служб нужен **пароль приложения**
   (создаётся в настройках безопасности почтового ящика), обычный пароль не подойдёт:

   | Почта | Сервер | Порт | Шифрование |
   |-------|--------|------|-----------|
   | Яндекс | `smtp.yandex.ru` | 465 | SSL/TLS |
   | Mail.ru | `smtp.mail.ru` | 465 | SSL/TLS |
   | Gmail | `smtp.gmail.com` | 587 | STARTTLS |
   | Корпоративный сервер | уточните у администратора | 25 / 587 / 465 | — |

   Логин — полный адрес ящика; «Отправитель» — тот же адрес; «Получатель(и)» — один или
   несколько адресов через запятую. Нажмите **«Отправить тестовое письмо»**.
3. **Отчёт по расписанию**: «Каждые N минут» или «Ежедневно» со списком времени (`09:00, 18:00`).
   **«Отправить отчёт сейчас»** — проверка.
4. Вкладка **«Журнал»** — просмотр событий, фильтр, экспорт в CSV, снимки (двойной щелчок).
5. Вкладка **«Диагностика»** — нагрузка на CPU, NPU, память, температура, время обработки кадра,
   диск и почта в реальном времени (зелёный — норма, жёлтый — повышенная, красный — высокая).

### 7.6. Общие

* **Язык интерфейса** — «Как в системе» (по умолчанию), русский или английский; окно настроек
  перестраивается сразу после «Применить».
* **Значок в трее** — монохромный; цвет подбирается по теме оформления, либо выберите светлый/тёмный.

* **Автозапуск** — включён по умолчанию.
* **Нагрузка на систему** — значения по умолчанию уже оптимальны для ROCK 5T
  (5 / 2 кадр/с, кадр детектора 320 px, полный просмотр кадра раз в 1 с, взгляд 2,5 раза/с,
  ядра `auto` = A55, nice 10).
  Ядра и приоритет применяются после перезапуска программы.

> **Справка по параметрам.** На вкладке **«Помощь»** описан каждый параметр: что он означает, на что
> влияет и какое значение по умолчанию; есть поиск. Та же подсказка появляется при наведении мыши на
> параметр, а клавиша **F1** открывает справку по текущей вкладке.

## 8. Проверка работы

| Проверка | Ожидаемый результат |
|----------|---------------------|
| Сесть перед камерой | значок в трее зелёный, в подсказке — ваше имя |
| Отойти от экрана дольше таймаута п.3 | экран блокируется |
| Попросить коллегу (не из базы) встать рядом, п.5 включён | через время подтверждения экран блокируется |
| Отвести взгляд (п.6 включён) | красная рамка → мигающая рамка → звук → письмо на e-mail (если включено) |
| Вернуть взгляд на экран | рамка и звук сразу исчезают |
| Вкладка «Журнал» | события по выполненным проверкам |
| Почта | письма по отмеченным событиям, отчёт по расписанию |

## 9. Автозапуск, обновление, удаление

**Автозапуск.** Программа сама создаёт файл `~/.config/autostart/eyetracker.desktop` и стартует
при входе пользователя в графический сеанс. Проверьте после перезагрузки, что значок появился в трее.

**Обновление.** Настройки, база лиц, журнал и загруженные звуки хранятся отдельно от программы
(`~/.config/eyetracker`, `~/.local/share/eyetracker`) и при обновлении сохраняются.

1. Закройте программу: меню трея → «Выход» (с паролем администратора).
2. Получите новую версию.
   * Если программа ставилась через git:

     ```bash
     cd ~/eyetracker && git pull
     ```

   * Если ставилась из ZIP-архива: скачайте новый архив, удалите старую папку `~/eyetracker`
     и распакуйте новый архив на её место (как в [разделе 4](#4-получение-программы)).
3. Запустите установщик (он же обновляет):

   ```bash
   cd ~/eyetracker && ./install.sh
   ```

4. Проверьте версию и вывод самопроверки в конце работы установщика:

   ```bash
   ~/.local/bin/eyetracker --version
   ```

5. Запустите программу из меню приложений («CAMAI бдительность — настройки») или выйдите из системы
   и войдите снова.
6. Если включён контроль взгляда — **выполните калибровку заново** (Настройки → «Взгляд» →
   «Калибровать…» → «Применить»). При обновлении с 1.0 на 1.1 это обязательно: изменился способ
   оценки взгляда.

**Откат на предыдущую версию** (если программа ставилась через git). Список версий:

```bash
cd ~/eyetracker && git log --oneline
```

Переход на нужную версию по её номеру из списка (например, `cadee3d` — версия 1.0) и установка:

```bash
cd ~/eyetracker && git checkout cadee3d && ./install.sh
```

Возврат к последней версии:

```bash
cd ~/eyetracker && git checkout claude/confident-lamport-ak9j6q && ./install.sh
```

**Удаление:**

```bash
cd ~/eyetracker && ./uninstall.sh
```

Сохраняет настройки, базу лиц и журнал. Полное удаление со всеми данными:

```bash
cd ~/eyetracker && ./uninstall.sh --purge
```

## 10. Решение проблем

Подробный технический журнал: `~/.local/share/eyetracker/eyetracker.log`. Для диагностики
выйдите из программы через трей и запустите её в терминале с подробным выводом:

```bash
~/.local/bin/eyetracker --debug
```

### Камера недоступна («Камера «0» недоступна», серый значок)

* Укажите в настройках точное устройство из `v4l2-ctl --list-devices` (см. раздел 3).
* Проверьте членство в группе `video`: команда `groups` должна содержать `video`; если нет —
  выйдите из системы и войдите снова.
* Камеру может занимать другая программа (видеосвязь, браузер): `fuser -v /dev/video20`.

### MIPI-камера

Камера по MIPI CSI на RK3588 работает через ISP (`rkisp`) и многоплоскостной интерфейс V4L2,
который сборка OpenCV из pip не поддерживает; поддержки GStreamer в ней тоже нет, а системный
`python3-opencv` в Debian 12 слишком старый (4.6, нужна ≥ 4.8). Поэтому **рекомендуется USB-камера**.
Если нужна именно MIPI-камера — включите её оверлей в `rsetup` и пробросьте поток в виртуальное
USB-подобное устройство через `v4l2loopback` (на реальной плате этот путь не проверялся):

```bash
sudo apt install -y v4l2loopback-dkms gstreamer1.0-tools gstreamer1.0-plugins-good
```

```bash
sudo modprobe v4l2loopback video_nr=42 card_label=eyetracker exclusive_caps=1
```

```bash
gst-launch-1.0 v4l2src device=/dev/video11 ! video/x-raw,format=NV12,width=640,height=480 ! videoconvert ! video/x-raw,format=YUY2 ! v4l2sink device=/dev/video42
```

После этого укажите в настройках источник `/dev/video42`. Номер `/dev/video11` для MIPI-камеры
уточните по `v4l2-ctl --list-devices` (устройство `rkisp_mainpath`).

### Экран не блокируется

* Нажмите «Проверить блокировку сейчас» и посмотрите сообщение.
* Укажите свою команду из таблицы в [п.7.3](#73-блокировка-пункты-35); проверьте её в терминале.
* Если «Состояние блокировки определяется: нет», повторная блокировка выполняется только после
  того, как условие пропадёт и возникнет снова — это нормально.

### Нет звука

* Проверьте воспроизведение в терминале:

  ```bash
  paplay ~/.local/share/eyetracker/sounds/builtin/beep.wav
  ```

* Выберите устройство вывода (HDMI/наушники) в настройках звука рабочего стола; проверьте громкость
  на вкладке «Взгляд».

### Рамка не видна поверх полноэкранных окон

Перейдите на сеанс X11 (см. [п.2.3](#2-подготовка-системы)).

### NPU не используется («нейросети: CPU» на вкладке «Камера»)

Проверьте `~/.local/bin/eyetracker --check` — строка «NPU RK3588» объясняет причину:

* «не найдена librknnrt.so» — повторите `./install.sh` (нужен доступ к raw.githubusercontent.com);
* «устройство NPU не найдено» — в ядре нет драйвера `rknpu`
  (проверка: `sudo cat /sys/kernel/debug/rknpu/version`);
* ошибка `rknn_init` / нет доступа к устройству — выйдите из системы и войдите снова (после
  установки пользователь добавляется в группу `render`).

Подробная проверка с замерами:

```bash
~/.local/share/eyetracker/venv/bin/python ~/eyetracker/scripts/npu_check.py
```

### Не устанавливается LiteRT

Установите без него — модель точек лица будет выполняться через OpenCV (точность та же,
нагрузка в режиме контроля взгляда немного выше):

```bash
cd ~/eyetracker && WITH_LITERT=0 ./install.sh
```

### Не скачиваются модели

Скачайте файлы на другом компьютере и положите в `~/.local/share/eyetracker/models/`:

* https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_detection_yunet/face_detection_yunet_2023mar.onnx
* https://media.githubusercontent.com/media/opencv/opencv_zoo/main/models/face_recognition_sface/face_recognition_sface_2021dec.onnx
* https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task

Затем проверьте командой `~/.local/bin/eyetracker --check`.

### Часто распознаёт как постороннего / не узнаёт

* Добавьте образцы («Добавить образцы…») при обычном рабочем освещении, в очках и без.
* Уменьшите «Порог сходства» до 0.36–0.38.
* Уберите контровой свет (окно за спиной), камера должна видеть лицо анфас.

### Высокая нагрузка на процессор

На вкладке «Общие» уменьшите частоты анализа (например 3 / 1 кадр/с), ширину кадра детектора
(240 px), увеличьте интервал полного просмотра кадра, уменьшите частоту оценки взгляда или
отключите точную оценку взгляда (тогда — по повороту головы). Проверить нагрузку: `top -p $(pgrep -d, -f "m eyetracker")`.

### Забыт пароль администратора

Завершите программу командой `pkill -f "m eyetracker"`, затем откройте `~/.config/eyetracker/config.json` и очистите учётные данные в разделе `auth`:

```json
"auth": { "username": "", "password_hash": "", "salt": "", "iterations": 200000 }
```

При следующем запуске программа предложит задать новые логин и пароль.

> Пароль защищает настройки от изменения через графический интерфейс. Пользователь, имеющий
> доступ к терминалу под той же учётной записью, может завершить программу. Для строгого
> контроля пользователю не следует выдавать права `sudo` и доступ к терминалу.
